# 🎵 Musicly - Music Streaming Platform

Musicly is a responsive music streaming website designed with a modern and attractive interface. It provides users with an enjoyable experience to explore trending artists, music genres, premium plans, and featured playlists.

## ✨ Features

- 🎧 Beautiful and responsive UI
- 🎵 Trending artists section
- 🎼 Multiple music categories
- 💎 Premium subscription section
- 📱 Mobile-friendly design
- 🚀 Smooth navigation
- 🎨 Modern animations and styling

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts

## 📂 Project Structure

```
Musicly/
│── index.html
│── images/
│── assets/
│── css/
│── js/
```

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/musicly.git
```

2. Open the project folder.

3. Run `index.html` in your browser.
