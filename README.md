🎵 Musicly — Music Streaming Platform

Musicly is a modern, responsive music streaming website designed to deliver an engaging and visually appealing music discovery experience. Explore trending artists, discover different music genres, browse featured playlists, and explore premium subscription plans through a clean and user-friendly interface.

✨ Features

🎧 Modern UI: Attractive layout with stylish visuals and smooth animations.

🎤 Trending Artists: Discover popular and featured artists.

🎼 Music Categories: Explore music across multiple genres.

🎶 Featured Playlists: Browse curated music collections.

💎 Premium Plans: Explore subscription options and premium features.

📱 Responsive Design: Optimized for desktop, tablet, and mobile devices.

🧭 Smooth Navigation: Easy-to-use navigation between website sections.

🎨 Interactive Styling: Modern typography, animations, and visual effects.

🛠️ Technologies Used

HTML5 — Website structure and content.

CSS3 — Styling, layouts, responsive design, and animations.

Google Fonts — Enhanced typography and visual presentation.
